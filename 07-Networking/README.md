# Linux Networking Practical

This section documents my hands-on practice with basic networking commands using Ubuntu Linux on Killercoda.

## Topics Covered

- Understanding IP addresses
- Checking network interfaces
- Viewing network configuration
- Understanding default gateways
- Testing network connectivity
- Checking network routes

## Commands Practiced

```bash
ip addr
hostname -I
ip route
ping -c 4 google.com
```

## Practical Results

- Identified the IP addresses of network interfaces.
- Checked the default gateway.
- Viewed the network routing table.
- Successfully tested internet connectivity using ping.

## Practical Environment

- Platform: Killercoda
- Operating System: Ubuntu Linux

## Learning Outcome

Gained practical experience with IP addresses, network interfaces, routing, and connectivity testing.
