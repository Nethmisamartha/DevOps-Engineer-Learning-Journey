# Linux Process and Services Practical

This section documents my hands-on practice with Linux process and service management using Ubuntu Linux on Killercoda.

## Topics Covered

- Viewing running processes
- Monitoring system processes
- Finding process IDs
- Starting and stopping services
- Checking service status
- Managing services using systemctl

## Commands Practiced

```bash
ps aux
top
pgrep nginx
sudo systemctl status nginx
sudo systemctl stop nginx
sudo systemctl start nginx
```

## Practical Results

- Monitored running Linux processes.
- Identified Nginx process IDs.
- Stopped and restarted the Nginx service.
- Verified the service status.

## Practical Environment

- Platform: Killercoda
- Operating System: Ubuntu Linux

## Learning Outcome

Gained practical experience in Linux process monitoring and service management.
