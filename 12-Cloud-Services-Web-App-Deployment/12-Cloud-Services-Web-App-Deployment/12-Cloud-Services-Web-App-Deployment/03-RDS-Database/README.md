# Amazon RDS – MySQL Database

## Activities
- Created a MySQL database using Amazon RDS.
- Connected to RDS from the Ubuntu EC2 instance.
- Installed the MySQL client.
- Configured SSL connection.
- Created a database named devops_practice.
- Created a students table.
- Inserted sample student records.
- Retrieved records using SELECT queries.
- Deleted the RDS instance after testing to avoid ongoing charges.

## Learning Outcomes
- Understood managed relational databases.
- Practised MySQL database operations.
- Learned secure connectivity between EC2 and RDS.
- Explored database resource management.
