# Module 03 – Cloud Services & Web App Deployment

## Overview
This project is part of my DevOps Engineer Learning Journey (Day 11 – Day 15).

The main objective was to explore AWS cloud services and deploy a web application using an Ubuntu EC2 instance.

## AWS Services Explored

### 1. Amazon EC2 – Compute Services
- Created and connected to an Ubuntu EC2 instance.
- Installed and configured Apache Web Server.
- Checked server status and system information.

### 2. Amazon S3 – Object Storage
- Created an S3 bucket.
- Uploaded a file to the bucket.
- Explored bucket security and encryption settings.

### 3. Amazon RDS – Managed Database
- Created a MySQL database using Amazon RDS.
- Connected to the database from the EC2 instance.
- Created a database and students table.
- Inserted sample records and tested SQL queries.
- Deleted the database after testing to avoid ongoing charges.

### 4. Amazon VPC – Virtual Networking
- Explored the default VPC.
- Inspected subnets and route tables.
- Explored Internet Gateway configuration.

### 5. AWS IAM – Security
- Explored IAM roles, users, and policies.
- Reviewed AWS access management features.

### 6. Amazon CloudWatch – Monitoring
- Explored EC2 monitoring metrics.
- Viewed CPU utilization graphs.
- Inspected CloudWatch Logs and Alarms.

## Web Application Deployment

Successfully deployed a simple HTML website using:
- Amazon EC2
- Ubuntu Server
- Apache Web Server
