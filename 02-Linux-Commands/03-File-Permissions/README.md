# Linux File Permissions

This section documents my practical experience with Linux file permissions using Ubuntu Linux on Killercoda.

## Topics Covered

- Understanding Linux file permissions
- Read, Write, and Execute permissions
- Using chmod command
- Checking file permissions
- Understanding permission notation

## Commands Practiced

```bash
ls -l
chmod 644 notes.txt
```

## Permission Example

`-rw-r--r--`

- Owner: Read and Write
- Group: Read
- Others: Read

## Practical Environment

- Platform: Killercoda
- Operating System: Ubuntu Linux

## Learning Outcome

Learned how to view and modify file permissions in Linux.
