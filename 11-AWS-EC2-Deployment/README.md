# AWS EC2 Deployment

## Project Overview
This practical demonstrates how to launch and configure an Ubuntu EC2 instance on AWS and deploy a simple website using Nginx.

## Environment
- Cloud Provider: AWS
- Service: Amazon EC2
- Operating System: Ubuntu 24.04 LTS
- Instance Type: t3.micro
- Web Server: Nginx

## Tasks Completed
1. Created an AWS EC2 instance.
2. Configured Security Group inbound rules.
3. Connected to the instance using SSH.
4. Updated Ubuntu packages.
5. Installed and started Nginx.
6. Deployed a simple website on the EC2 instance.
